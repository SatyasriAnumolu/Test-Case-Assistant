## Important Notes

### ⚠️ Known Limitations (Minor)

1. **Area Path Filtering Context**
   - Requires manual re-sync after changing area path filter
   - Not a code bug, but UX gap (users may not realize)

2. **Validation Focus Management**
   - Uses placeholder-based querySelector
   - Works reliably but could use refs for robustness
   - Non-critical: tab order works fine

3. **Empty State Complexity**
   - Tracks both `validationErrors` and `showValidation`
   - More complex than single empty state
   - But provides better UX

### ✅ Recommended Next Steps

1. Add real-time validation on blur (optional enhancement)
2. Use refs for focus management (reliability improvement)
3. Consider UX flow for area path filter changes
4. Add analytics for validation failures
5. Plan user onboarding for validation feature
